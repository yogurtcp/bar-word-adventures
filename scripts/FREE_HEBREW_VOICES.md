# Free Hebrew narration evaluation

The owner requested a free replacement for the current Hebrew voice. Google
Kore migration preparation was withdrawn before generating audio or making
any paid requests. The published recordings are still the existing Hila clips.

The leading candidate is **BlueTTS 2.5**, a locally run, Hebrew-capable TTS engine.
It can generate bundled recordings on this workstation without an API account,
subscription, metered service or separate server for the installed apps.
The app would continue playing static MP3s offline.

Before a full migration, audition the same real game instructions, letter names
and short words in at least two voice styles. Keep current recordings until
pronunciation and quality have been reviewed. New recordings must use fresh
filenames and be released with the corresponding manifests and offline caches;
retain saved progress, settings and startup-only update behavior.

Upstream: [BlueTTS engine (MIT)](https://github.com/maxmelichov/BlueTTS),
[author's demo and local-generation description](https://bluetts.com/),
[2.5 model and voice provenance](https://huggingface.co/notmax123/BlueTTS2.5-onnx),
[ReNikud Hebrew pronunciation frontend (CC BY 4.0)](https://github.com/renikud/renikud).
Use the model's explicitly attributed LibriTTS-R voice styles for auditions;
its model card documents those references as CC BY 4.0 (Google LLC).

No new voice is selected or represented as published by this evaluation note.

[Listen to the locally generated audition](https://yogurtcp.github.io/bar-word-adventures/voice-preview.html).
